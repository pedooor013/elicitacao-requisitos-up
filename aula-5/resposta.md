# Levantamento de Requisitos

## Secretaria — Registrar a Matrícula de um Novo Aluno

| Item | Descrição |
|---|---|
| **Processo** | A secretária deve coletar os dados dos alunos para realizar a matrícula. |
| **Técnica** | Entrevista |
| **Motivo** | Como é um processo muito padronizado, uma breve entrevista levantando requisitos e entendendo o que pode ser melhorado já é o suficiente para o desenvolvimento correto. |

---

## Professor — Registrar a Frequência dos Alunos

| Item | Descrição |
|---|---|
| **Processo** | Registrar a frequência dos alunos que chegam na aula atrasados ou no horário, além de registrar as faltas. |
| **Técnica** | Observação |
| **Motivo** | A observação é ideal para entender como os professores registram a frequência, permitindo definir um horário ou até marcar por aula (em casos de duas ou mais aulas seguidas da mesma turma). Observando, é possível ver como o professor divide a frequência e qual o melhor jeito de otimizar essa ação. |

---

## Aluno — Marcar uma Aula de Reposição quando Falta

| Item | Descrição |
|---|---|
| **Processo** | Marcar uma aula de reposição. |
| **Técnica** | Questionário + Entrevista |
| **Motivo** | O questionário deve ser respondido por todos os alunos, e os professores devem perguntar aos alunos diretamente, para entender o que sentem falta na hora de marcar uma reposição. Dessa forma, entrevista e questionário são os melhores caminhos para definir o que deve ser feito. |
| **Observação** | Como os professores não têm experiência em coletar requisitos, a entrevista deve ser bem estruturada, com um fluxo bem definido para eles seguirem. |
